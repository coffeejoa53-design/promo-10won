# 홍합몰 어드민 — 사장님이 직접 할 것 (딱 5단계, 10분)

> 어드민 주소: **https://promo-10won.vercel.app/admin**
> 코드는 전부 만들어져 있고, 배포도 돼 있습니다. 남은 건 **키가 필요한 화면 3개**뿐인데,
> 키·비밀번호는 Claude가 대신 넣을 수 없어서(보안 규칙) 사장님이 직접 넣으셔야 합니다.
> 사무실에서 Claude in Chrome 을 켜고 "어드민 세팅 같이 하자"고 하시면 화면을 같이 보며 진행합니다.
> **키 값을 채팅창에 붙여넣지 마세요.** Vercel·Supabase 화면에만 넣으면 됩니다.

## 1. Supabase 프로젝트 만들기 (DB)

1. https://supabase.com → 구글 계정(coffeejoa53)으로 로그인
2. **New project** → 이름 `sambo-admin`, Region **Northeast Asia (Seoul)**, DB 비밀번호는 자동생성 그대로 (어디 적어둘 필요 없음)
3. 1~2분 기다리면 프로젝트가 열립니다

## 2. 표 만들기 (SQL 한 번 실행)

1. 왼쪽 메뉴 **SQL Editor** → **New query**
2. 이 저장소의 `supabase/migrations/20260912000001_sambo_admin.sql` 파일을 메모장으로 열어 **전체 복사 → 붙여넣기**
3. **Run** 클릭 → "Success" 가 나오면 끝. (여러 번 실행해도 안전합니다)

이걸로 표 4개(채널·링크 장부·클릭 로그·랜딩 행동)와 기본 채널 9개가 들어갑니다.

## 3. 키 2개 확인하기 (Supabase)

왼쪽 메뉴 **Project Settings → API** 에서:

| 이름 | 어디 있나 |
|---|---|
| `SUPABASE_URL` | Project URL (https://xxxx.supabase.co) |
| `SUPABASE_SERVICE_ROLE_KEY` | Project API keys → **service_role** (secret) 옆 「Reveal」 |

service_role 키는 **서버에서만** 씁니다. 브라우저·랜딩 코드에는 절대 들어가지 않습니다.

## 4. Vercel 에 환경변수 3개 넣기

1. https://vercel.com → **promo-10won** 프로젝트 → **Settings → Environment Variables**
2. 아래 3개를 하나씩 추가 (Environment 는 Production·Preview·Development 전부 체크)

| Key | Value |
|---|---|
| `SUPABASE_URL` | 3번에서 본 Project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | 3번에서 본 service_role 키 |
| `ADMIN_PASSCODE` | **사장님이 정하는 어드민 비밀번호** (8자 이상, 영문+숫자 섞어서) |

## 5. 다시 배포하고 들어가기

1. Vercel → **Deployments** → 맨 위 배포 오른쪽 「⋯」 → **Redeploy**
2. 1분 뒤 https://promo-10won.vercel.app/admin → 4번에서 정한 비밀번호로 들어가기
3. 「링크 만들기」에서 채널 고르고 → 링크 만들기 → 짧은 주소 복사

## 이게 뭘 하는 건가 (한 줄씩)

| 화면 | 하는 일 |
|---|---|
| **링크 만들기** | 뿌릴 자리(블로그 글·인스타·카톡…)를 고르면 UTM 꼬리표가 붙은 주소와 **짧은 주소**(`promo-10won.vercel.app/l/blog-post01`)를 만들어 줍니다 |
| **링크 장부** | 만든 링크 전부와 누적 클릭 수. 복사 버튼으로 바로 붙여넣기 |
| **성과** | 클릭(짧은 주소 누른 수) → 도달(랜딩에 들어온 수) → 전환(「스토어에서 쿠폰 받기」 누른 수)을 채널별·일별로 |

**전환의 정의:** 지금 랜딩에는 신청 폼이 없고 버튼이 스마트스토어로 넘어가므로, "쿠폰 받기 버튼을 누른 것"을 전환으로 셉니다.
나중에 카카오채널·신청 폼 같은 진짜 가두리망이 생기면 그 버튼을 전환으로 바꾸면 됩니다 (`track.js` 의 `a.cta` 부분).

| 외부 권한 | 없음 (GA·구글 클라우드 연결은 아직 안 함 → 5회차 과제 01-3 은 다음 단계) |
| 테스트 데이터 | 세팅 후 Claude 가 확인용으로 만드는 링크는 코드에 `test` 가 들어갑니다. 장부에서 「보관」하면 됩니다 |

## 보안 자체 점검 (5회차 과제 01-4 기준)

| 항목 | 결과 |
|---|---|
| 실제 수집 항목 = 처리방침 항목 | 개인정보 수집 없음 → 처리방침에 적을 항목 없음. (랜딩에 폼을 붙이는 날 3회차 스킬로 방침 3종 생성) |
| 어드민에 아무나 못 들어온다 | 비밀번호 + HMAC 서명 쿠키(httpOnly·Secure). 관리 API 전부 인증 뒤. 실패 시 0.6초 지연 |
| 키·비밀번호가 코드에 없다 (GitHub 포함) | 없음. 전부 Vercel 환경변수. 응답에도 안 실림 |
| Supabase RLS 가 열려 있지 않다 | 표 4개 전부 RLS 켜짐 + anon/authenticated 권한 회수. 브라우저는 DB 에 직접 닿지 않음 |
| 동의 체크박스 분리 | 해당 없음 (폼 없음) |
| 오픈 리다이렉트 | 짧은 링크 목적지는 DB 의 url 뿐이고, 그것도 우리 도메인일 때만 |
