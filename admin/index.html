들어가기

사장님만 보는 화면입니다. Vercel 에 넣어 둔 어드민 비밀번호를 입력하세요.

1. 어디에 뿌릴 링크인가요?

뿌리는 자리마다 다른 링크를 씁니다. 같은 링크를 세 군데에 던지면 세 군데를 구분할 수 없어요. 여러 개를 골라 한 번에 만들 수 있습니다.

채널 추가 · 숨기기

숨기기는 카드 안의 「숨기기」를 누르세요. 숨긴 채널의 링크는 그대로 살아 있습니다.

2. 어떤 건인가요?

캠페인은 묶음 이름입니다. 한 번 정하면 바꾸지 마세요. 소재는 같은 자리에 여러 번 뿌릴 때 구분하는 번호예요.

영문·숫자·하이픈. 예: honghap-10won, chuseok-2026
채널 하나를 고르면 다음 번호를 제안합니다
고급: 검색 키워드(utm_term) · 직접 입력
채널을 고르면 만들어질 주소를 미리 보여 줍니다.
